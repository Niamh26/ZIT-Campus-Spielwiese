ZIT-CAMPUS – 3D-SCHÄDELPUZZLE: WINDOWS-INSTALLATION
==================================================

Diese ZIP ist für den Einbau in dein bestehendes GitHub-Repository gedacht.
Die Webseite selbst ist bereits auf lokale Dateien eingestellt.

SO GEHT'S
---------
1. ZIP entpacken bzw. den Inhalt in dein lokales GitHub-Repository kopieren.
2. Doppelklick auf: SCHAEDELPUZZLE-INSTALLIEREN.bat
3. Das schwarze/PowerShell-Fenster offen lassen, bis „FERTIG“ erscheint.
4. Danach GitHub Desktop öffnen.
5. Prüfen, dass unter games/schaedel-puzzle/models viele .stl-Dateien erscheinen
   und unter games/schaedel-puzzle/vendor/three die Three.js-Dateien liegen.
6. Commit erstellen und „Push origin“ klicken.
7. Nach dem GitHub-Pages-Deployment die Spielwiese neu laden (ggf. Strg+F5).

WAS DER INSTALLER LÄDT
----------------------
- Three.js r180 (lokal in games/schaedel-puzzle/vendor/three)
- OrbitControls, TransformControls und STLLoader
- 22 anatomische BodyParts3D/FMA-Schädelknochen als STL

Danach benötigt das veröffentlichte Schädelpuzzle KEINEN externen Modell-Download.
Die Dateien werden direkt aus deinem GitHub-Pages-Projekt geladen.

SCHMETTERLINGSWIESE
-------------------
Das Puzzle ist an ZITPoints angebunden. Beim ersten vollständigen Lösen werden
20 Punkte für die Schmetterlingswiese vergeben.

LIZENZ / QUELLE
----------------
Hinweise zu BodyParts3D befinden sich in:
games/schaedel-puzzle/ATTRIBUTION.md

FEHLERBEHEBUNG
---------------
Wenn Windows PowerShell den Download blockiert:
- Internetverbindung prüfen.
- SCHAEDELPUZZLE-INSTALLIEREN.bat erneut per Doppelklick starten.
- Falls eine konkrete Datei als Fehler angezeigt wird, Screenshot der Meldung senden.

Wenn GitHub Desktop danach sehr viele neue Dateien zeigt: Das ist korrekt.
Die .stl-Modelle und die lokalen Three.js-Dateien müssen mit hochgeladen werden.
