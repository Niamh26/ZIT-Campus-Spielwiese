# Trauma-Kreislauf – aktualisierte Version

Diese Version enthält:

- das neue Übersichtsfoto `images/uebersicht.jpg`
- die zusätzliche Station aus `Bild 8a`
- insgesamt 12 Spielstationen
- das Abschlussbild `images/abschluss-13.jpg`

## Besonderer Abschluss

Während des Spiels bleibt Bild 1 unverändert. Erst wenn alle zwölf Stationen korrekt eingesetzt wurden, wird Bild 1 automatisch durch Bild 13 mit dem Superhelden-Umhang ersetzt. Es entsteht kein zusätzlicher Kreis.

## Einsetzen

Den kompletten Ordner `trauma-kreislauf` nach `games/` kopieren und den vorhandenen Ordner ersetzen.
