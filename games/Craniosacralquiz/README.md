# ZIT Campus – Craniosacral-Quiz

Eine eigenständige, responsive Quiz-Seite ohne externe Bibliotheken.

## Dateien

- `index.html` – Seitenstruktur
- `style.css` – Gestaltung
- `script.js` – 10 Fragen, Auswertung und Neustart
- `skool-post.txt` – fertiger Ankündigungstext für Skool

## Einbau in das GitHub-Repository

1. Im Repository einen neuen Ordner `craniosacral-quiz` anlegen.
2. `index.html`, `style.css` und `script.js` in diesen Ordner kopieren.
3. In der Startseite der Spielwiese einen Link ergänzen:

```html
<a href="craniosacral-quiz/index.html">Craniosacral-Quiz starten →</a>
```

4. In GitHub Desktop prüfen, ob die vier neuen/geänderten Dateien unter **Changes** erscheinen.
5. Als Summary eintragen: `Craniosacral-Quiz hinzugefügt`
6. **Commit to main** wählen und danach **Push origin**.
7. Auf GitHub Pages testen.

## Zurück-Link

Die Quiz-Seite verweist mit `../index.html` zurück zur Startseite. Falls die Startseite
anders heißt oder an einem anderen Ort liegt, den Link in `index.html` anpassen.

## Inhaltlicher Hinweis

Das Quiz unterscheidet anatomische Fakten, das therapeutische Modell und die
wissenschaftliche Evidenz. Es enthält keine Heilversprechen und ersetzt keine
medizinische Abklärung.
