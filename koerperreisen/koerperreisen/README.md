## GitHub Repository

Empfohlener Repository-Name:

ZIT-Campus-Koerperreisen

GitHub Pages nach dem Push aktivieren:
Settings → Pages → Deploy from a branch → main → /(root)

Danach ist die Startseite erreichbar unter:

https://niamh26.github.io/ZIT-Campus-Koerperreisen/

Die erste Reise ist erreichbar unter:

https://niamh26.github.io/ZIT-Campus-Koerperreisen/craniosacrales-system/

## Link im ZIT Campus / Skool

In der Skool-Seite „Körperreisen“ als Link genau eintragen:

https://niamh26.github.io/ZIT-Campus-Koerperreisen/

Damit gelangen die Teilnehmer zuerst auf die Körperreisen-Übersicht
und wählen dort die gewünschte Reise.
