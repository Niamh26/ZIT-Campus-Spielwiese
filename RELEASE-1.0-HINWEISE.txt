Installation:
1. ZIP entpacken.
2. Den INHALT des entpackten Ordners in das bestehende Repository
   „ZIT-Campus-Spielwiese“ kopieren.
3. Vorhandene Dateien bei Nachfrage ersetzen.
4. Den vorhandenen .git-Ordner im Repository nicht löschen.
5. In GitHub Desktop committen und anschließend „Push origin“ wählen.

Wichtig:
Die ZIP enthält bewusst keinen .git-Ordner. Dadurch bleibt die bestehende
GitHub-Verknüpfung auf deinem Computer erhalten.
